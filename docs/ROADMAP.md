# Roadmap

This roadmap is a planning document, not a commitment. Mark items only after maintainers have agreed on scope.

## Current priorities

- [ ] Verify and document local setup from a clean clone.
- [ ] Add or improve automated tests.
- [ ] Document the real-time event protocol.
- [ ] Add screenshots and a collaboration demo.
- [ ] Improve accessibility and keyboard support.

## Potential directions

- [ ] Additional canvas tools.
- [ ] Export and import workflows.
- [ ] Board persistence and recovery.
- [ ] Presence indicators and participant cursors.
- [ ] Undo and redo across collaborative sessions.
- [ ] Performance improvements for large boards.

## Proposing a roadmap item

Open a feature request with the user problem, proposed behaviour, alternatives, and implementation considerations.
